# Shreyas Raut - Portfolio

Welcome to my personal portfolio repository! This project showcases my experience, skills, and projects as a Software Engineer.

## Live Demo
Check out the live portfolio: [Shreyas Raut Portfolio](https://shreyasraut0707.github.io/Portfolio/)

## Tech Stack
- **Frontend**: React, TypeScript, HTML5, CSS3 (Glassmorphism & Light Theme)
- **Build Tool**: Vite
- **Deployment**: GitHub Pages

## Features
- **Responsive Design**: fully optimized for desktop, tablet, and mobile.
- **Modern UI**: Clean light theme with soft glassmorphism effects, crisp typography, and smooth transitions.
- **Dynamic Data**: All resume data (skills, experience, projects, education) is maintained cleanly in a central TypeScript file (`src/data/resume.ts`).

## Project Structure
```text
├── public/                # Static assets like certificates and images
├── src/
│   ├── assets/            # Project-specific static assets
│   ├── components/        # Reusable React components (Header, Hero, Experience, Projects, etc.)
│   ├── data/              # Centralized data sources (resume.ts)
│   ├── styles/            # CSS files for styling components and global design system
│   ├── App.tsx            # Main application component
│   └── main.tsx           # Application entry point
├── index.html             # HTML template
├── package.json           # Dependencies and build scripts
└── vite.config.ts         # Vite bundler configuration
```

## Running Locally

To run this project locally, make sure you have Node.js installed, then follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shreyasraut0707/Portfolio.css
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
